Save data to GitHub

Attendance and tasks are stored in data/attendance.json and data/tasks.json in the repository. To save changes there, paste a GitHub token with write access to the repo. It is stored only in this browser.

Without a token, anything you submit is saved only in this browser.

Create one at GitHub → Settings → Developer settings → Fine-grained tokens, limited to this repository with Contents: Read and write.
